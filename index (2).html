الذكاء الاصطناعي المحلي المجاني (Ollama)

يمكنك تشغيل نموذج لغوي محلي على حاسوبك دون دفع اشتراك. يتطلب تثبيت Ollama وتنزيل نموذج مناسب، ثم تشغيل الخادم المحلي.

هذه ميزة اختيارية. لا يوجد اتصال بنموذج حقيقي حتى تضبط Ollama وتضغط اختبار الاتصال. لا نرسل محادثاتك إلى خدمة خارجية.
لم يتم اختبار الاتصال بعد.

طريقة الإعداد المجانية

  1. ثبّت Ollama من الموقع الرسمي: ollama.com
  2. افتح الطرفية واكتب: ollama run qwen2.5:3b
  3. اترك Ollama يعمل، ثم اضغط اختبار الاتصال هنا.
  4. إذا منع المتصفح الاتصال بسبب CORS، شغّل الخادم بإعداد OLLAMA_ORIGINS للسماح بأصل الصفحة، ثم أعد التشغيل.
